# KernWi‑Fi YSFReflector Dashboard

Production-grade YSFReflector deployment with real-time web dashboard, staging environment, and Git-managed lifecycle.

---

## 📡 Overview

This project provides a complete YSFReflector monitoring and management system including:

- Real-time reflector dashboard (HTML/JS)
- Python backend parser generating status.json
- C++ YSFReflector backend (DVReflectors)
- Staging environment for safe testing
- Git-based version control and rollback
